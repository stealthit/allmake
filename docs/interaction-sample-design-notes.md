# Interaction sample series — 2026-11-25

Six additional concepts bring the catalogue from 30 to 36 samples. Existing IDs are preserved. New codes: B-07, B-08, F-08, L-18, L-19, L-20.

## References and observations

- Studio JT: https://www.studio-jt.co.kr/ — dark editorial work grid, large split typography, image and pointer interaction. GDWEB listing https://www.gdweb.co.kr/sub/view.asp?str_no=28432 is dated 2026-11-24.
- Daum corporate: https://daumcorp.com/ — a dark planetary opening transitions into a blue full-screen scene with large centered type. This informs the chapter-based narrative direction.
- Dminusone: GDWEB https://gdweb.co.kr/sub/view.asp?str_no=28310 and DBCut https://www.dbcut.com/websites/25986 are dated 2026-11-13. The listed visual direction includes motion graphics, 3D and typography. DBCut direct access was restricted, so its internal interactions were not directly audited.
- Lusion: https://lusion.co/ describes its combination of design, motion and 3D. Detailed motion was not verified because its loader remained visible during the reference session.

These are observed references, not a claim that every current website follows these patterns. Layouts, copy and interaction code in these six samples are original. No reference screenshots, proprietary artwork or scripts are shipped.

## Implemented directions

| Code | Concept | Main interaction |
| --- | --- | --- |
| B-07 | Kinetic Play | Fine-pointer depth, kinetic type and selectable brand expression |
| B-08 | Orbit Flow | Product-state tabs and a scroll-linked chapter composition |
| F-08 | Precision Scrub | Keyboard-operable process slider and exploded-part illustration |
| L-18 | Slide Room | Native scroll-snap gallery with swipe, drag and previous/next controls |
| L-19 | Sensory Brew | Taste selection changes the palette and description; native detail disclosures |
| L-20 | Poster Stack | Selectable expanding poster panels, with a vertical mobile arrangement |

Motion is optional. Device reduced-motion preference starts the samples with motion off; an explicit toggle lets the visitor choose. Content remains visible without JavaScript, and touch/keyboard actions do not depend on hover. Native scrolling is preserved. Pointer work is batched with requestAnimationFrame; ambient animation pauses when offscreen or the document is hidden. Existing licensed Unsplash assets and the bundled Lucide pictograms are reused, with sources retained in the catalogue credits.
